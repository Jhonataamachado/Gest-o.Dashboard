# 📈 Painel de Gestão de Leads B2B

Dashboard interativo desenvolvido em Python para visualização e análise rápida de bases de contactos empresariais.

## 🚀 O Problema que Resolve
Transforma planilhas estáticas de prospeção num painel visual dinâmico. Permite às equipas comerciais visualizar o volume de leads extraídos e a distribuição geográfica (cidades alcançadas) de forma imediata, facilitando a tomada de decisão em campanhas de cold calling.

## 💻 Tecnologias
* Python 3: Lógica principal e processamento.
* Streamlit: Construção rápida da interface web interativa.
* Pandas: Leitura e manipulação estruturada de dados (ficheiros CSV).
